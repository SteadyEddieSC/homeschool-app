# Beaufort Learning Harbor v10.40

v10.40 centralizes the app shell and static role policy while preserving the current product experience.

## Adds

- Reusable schema-1 `app-shell-role-policy` module.
- One normalized source for the five role definitions.
- One authoritative runtime screen catalog.
- Static role authorization that fails closed for unknown roles and screens.
- Module-owned role landing defaults and navigation-group definitions.
- Read-only browser policy and runtime snapshots for diagnostics and regression testing.
- Node validation for duplicate screens, invalid roles/groups, dangerous keys, polluted prototypes, and inaccessible defaults.
- Desktop, touch-tablet, and Pixel 7 role-policy parity coverage.
- Updated v10.40–v10.49 roadmap.
- Preliminary 4th–6th curriculum booklist documentation with all missing confirmation fields explicitly identified.

## Preserved boundaries

- Existing Student, Parent, Teacher, Director, and Admin outcomes.
- Dynamic Student permissions and Life Skills learner settings.
- Adult Gate behavior.
- Existing routes, data schemas, Knowledge Check, Lesson Pack, Family Planner, rewards, completion, attendance, mastery, portfolio, and source records.
- Existing offline-runtime, console-quiet, bounded-mutation, visual, and deterministic single-file contracts.
- No live curriculum pacing generated from the preliminary booklist.
- No cloud account, API, database, telemetry, service worker, external calendar integration, broad redesign, or cross-project change.
