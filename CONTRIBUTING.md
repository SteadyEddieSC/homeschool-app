# Contributing

1. Start from `main` and create a short-lived branch.
2. Keep public fixtures synthetic.
3. Run `npm run verify` before opening a pull request.
4. Run full release and Playwright validation when the application artifact changes.
5. Include user impact, validation, and privacy impact in the pull request.
6. Prefer squash merge after checks pass.

Do not commit real family exports or screenshots with personal information.
