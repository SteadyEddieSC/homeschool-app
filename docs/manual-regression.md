# Manual Regression Priorities

Before tagging a release, verify at minimum:

- mobile dock does not flicker or replace its node
- all five dock actions route correctly
- student role shows student navigation only
- parent, teacher, director, and admin roles hide the student dock
- no adult proof action is confused with formal quiz/test results
- local state persists across reload
- export and restore work when changed
- the app remains usable with network access disabled
- the public demo contains synthetic identities only
