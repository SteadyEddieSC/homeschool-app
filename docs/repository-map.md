# Repository Map

- `source/releases/`: immutable, sanitized single-file releases and manifests
- `site/`: generated deployment output; not committed
- `modules/`: controlled source boundaries for future extraction
- `fixtures/`: synthetic scenario definitions
- `tests/`: Playwright browser tests
- `scripts/`: build, integrity, privacy, and local-server tools
- `docs/`: architecture, privacy, release, roadmap, and testing guidance
- `.github/`: CI and pull-request standards
