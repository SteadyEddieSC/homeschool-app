# v10.34 — Route and Role Regression Coverage

## Purpose

v10.34 strengthens the release gate around the app behaviors most likely to break during future modularization: exact student routing, role visibility, direct-screen navigation, and access boundaries.

## Integration correction

The legacy exact-route and final mobile-dock layers previously looked for global `activeStudent` and `activeRole` functions, while the core app intentionally kept those functions inside its closure. The route layer therefore fell back to a generic lower learner and student role. v10.34 bridges those layers to the persisted synthetic app state so Jordan, Avery, and adult role visibility resolve consistently without exposing core internals globally.

## Coverage added

- Upper learner: Learn → Honors Biology library, Practice → Biology lab, Quiz/Test → Quizzes & Tests, Proof → Assignments, Feedback → Portfolio.
- Lower learner: Learn → Botany library, Practice → Botany lab, Quiz/Test → Quizzes & Tests, Proof → safe Assignments fallback, Feedback → Portfolio.
- Every route returns deterministically to Home without replacing the authoritative mobile dock node.
- Parent, Teacher, Director, and Admin roles retain their intended allowed screens.
- Denied screens redirect safely to Home.
- Student mode hides adult-only navigation and controls.
- Student mode exposes the five-action dock at mobile width; adult modes hide it.
- The browser matrix covers Desktop Chrome, an 820×1180 touch tablet, and Pixel 7.
- The three viewport projects run as parallel GitHub Actions jobs, with artifact publication blocked until all pass.

## Preserved behavior

- Demo Family loading and resetting remain deterministic and browser-local.
- Hero/title content remains mutation-stable after startup.
- The mobile dock remains under one owner.
- Privacy scanning, exact artifact integrity, visual capture, and axe-core remain release gates.
- Cloudflare Workers deploys the generated `site` directory from `main`.
