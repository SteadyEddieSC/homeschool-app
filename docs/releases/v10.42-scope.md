# v10.42 — Family Planner v2

## Goal

Extend the existing adult-only Family/Co-op Planner with reusable week templates, non-destructive duplicate and roll-forward operations, deterministic workload/conflict analysis, clearer co-op responsibility gaps, and optional learner-safe print/CSV support.

## Scope

- Build deterministically from merged v10.41.
- Add `modules/family-planner-v2.mjs` with schema-1 validation.
- Add reusable browser-local week templates.
- Apply templates additively and skip already-linked template items.
- Duplicate active planner items into another loaded week without overwriting the target week.
- Roll active planner items forward as explicit carryover while preserving the source week.
- Analyze workload by day and learner/track target.
- Detect target-aware time overlaps.
- Detect enabled co-op items missing a responsible role or follow-up owner.
- Add optional learner-safe print preview and CSV export.
- Exclude adult-only notes, co-op arrival/handoff notes, reward data, attendance, mastery, and portfolio state from learner-safe output.
- Keep existing Family Planner package compatibility and source seeding/carryover behavior.
- Add Node and desktop/touch-tablet/Pixel 7 browser coverage.
- Advance the maintained roadmap through v10.51.

## Boundaries

- No automatic completion, XP, coins, grades, attendance, mastery, portfolio approval, or source-record mutation.
- No automatic calendar synchronization or network dependency.
- No silent target-week overwrite.
- No adult-only notes in learner-safe print or CSV output.
- Print and binder output remains optional support material only.
- No final curriculum pacing generated from preliminary curriculum sources.
- No cloud account, API, database, telemetry, service worker, cross-project infrastructure, or L2G changes.

## Acceptance criteria

- Templates, duplicate-week, and roll-forward operations are deterministic and fail closed on malformed inputs.
- Reapplying the same template or source week does not silently duplicate linked items.
- Source weeks and linked Assignment/Lesson Pack records remain unchanged.
- Workload, conflict, and responsibility-gap diagnostics are stable and understandable.
- Learner-safe print/CSV output excludes adult-only fields and works offline.
- Parent, Teacher, Admin, Director, and Student boundaries remain unchanged.
- Existing privacy, offline, role-policy, route-resolver, console/page-error, bounded-mutation, accessibility, data, visual, Knowledge Check, Lesson Pack, Family Planner v1, hero, dock, and destination gates remain green.
- Exact standalone artifact bytes and SHA-256 match the release manifest and downloadable Actions artifact.
