# v10.40 — App Shell and Role Policy Module

## Goal

Move screen-catalog membership, role metadata, static route authorization, role landing defaults, and navigation-group definitions behind one reusable tested contract without changing current role behavior.

## Scope

- Build deterministically from merged v10.39.1.
- Add `modules/app-shell-role-policy.mjs` with schema-1 validation.
- Normalize and freeze the five supported role definitions.
- Normalize the runtime screen catalog and reject duplicates, unsupported roles, invalid groups, dangerous keys, polluted prototypes, and inaccessible role defaults.
- Make unknown roles and unknown screens fail closed.
- Route `roleOptions()`, `screenCatalog()`, static `roleCanAccess()`, `roleDefaultScreen()`, and `navGroupsForRole()` through the module.
- Preserve dynamic Student permission checks, Life Skills learner settings, Adult Gate behavior, current navigation labels, and current route outcomes.
- Expose read-only `window.BLHAppShellPolicy` and `window.BLHRolePolicyRuntime` diagnostics.
- Add Node contract tests and desktop/tablet/Pixel 7 parity checks.
- Preserve the v10.39.1 console-quiet and bounded-mutation gates.
- Update the maintained roadmap through v10.49.
- Record the family-provided 4th–6th grade booklist as preliminary, edition-unconfirmed planning input only.

## Boundaries

- No broad visual redesign.
- No intended change to Student, Parent, Teacher, Director, or Admin access.
- No change to rewards, completion, attendance, mastery, portfolio approval, or source records.
- No final curriculum pacing generated from the preliminary booklist.
- No cloud account, API, database, telemetry, service worker, or external calendar dependency.
- No cross-project or L2G changes.

## Acceptance criteria

- One module owns normalized roles, catalog membership, static authorization, defaults, and navigation-group definitions.
- Direct-route and visible-navigation behavior remains parity-clean for all five roles.
- Unknown role/screen requests fail closed.
- Student attempts to enter adult-only surfaces return to Home.
- Existing desktop, touch-tablet, Pixel 7, route, role, accessibility, data, offline, visual, Knowledge Check, Lesson Pack, Family Planner, hero, dock, destination, privacy, and console-stability gates remain green.
- Exact standalone artifact bytes and SHA-256 match the release manifest and downloadable CI artifact.
